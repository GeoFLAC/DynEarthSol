Remeshing

We assess the mesh quality at fixed temporal intervals and use specific quality measures to decide whether to keep using the present mesh or remesh. For example, if the smallest angle of an element is less than a certain prescribed value, we remesh.

New mesh creation​

The default mode of remeshing is to create a new mesh preserving the old mesh's boundaries. The meshing libraries linked during the build are resued: triangle for 2D and tetgen for 3D. To assist the meshing process, DES provides a point set for the meshing libraries to start with. However, a group of nodes in the deformed mesh may be removed from the point set if any of the following criteria is met:

  • Left outside of the new boundaries when a deformed or displaced boundary is restored to the initial configuration
  • Surrounded only by small elements

Once all criteria are enforced, a final list of nodes is collected and used for constructing a new mesh. During the process, new nodes might be inserted into the mesh or the mesh topology changed through edge-flipping (see the figure below) during the triangulation.

(above) Plastic strain distribution on a mesh before and after remeshing. Solid and dashed white lines are new and old element edges. Pink circles are newly added nodes.

At extreme strain, a highly distorted mesh can have two boundary segments meeting at a tiny angle, which sends triangle's Steiner-point insertion into a non-terminating splitting loop. The 2D-only parameter mesh.max_steiner_factor (default 30) caps the number of Steiner points triangle may insert during remeshing at factor × npoints, bounding this runaway; set it <= 0 to restore the old unlimited behavior. It only applies when no area constraint is active, so initial meshing is unaffected.

Mesh optimization​

As described in Adaptive mesh refinement with MMG, a user can choose link MMG when building DES. MMG performs mesh optimization allowing a metric-based element size variation and the metric itself can be defined in terms of one of the physical variables like accumulated plastic strain.

Variable mapping from old to new mesh​

After the new mesh is created, the boundary conditions, derivatives of shape function, and mass matrix have to be re-calculated.

Also, an inter-mesh mapping of variables is performed. For data associated to nodes (e.g., velocity and temperature), we use linear interpolation of the data from the old mesh to evaluate the field at the new nodal location.

For data associated to elements (e.g., stress and strain), DES3D uses Superconvergent Patch Recovery (SPR) (Zienkiewicz & Zhu, 1992), blended with a plain nearest-neighbor (NN) remap, per element, by how elastic that element currently is:

  • SPR first projects each element's centroid value onto the nodes of its patch by fitting a linear polynomial in patch-relative coordinates, then evaluates that polynomial at each new nodal position. This produces a smooth, higher-order-accurate nodal field that is subsequently re-sampled back to the new element centroids, eliminating the spurious velocity spikes and checkerboard stress patterns that appeared with a plain nearest-neighbor scheme.

  • But SPR's smoothing also relaxes elastic stress that should instead carry over unchanged (a cold, slowly-deforming element's memory of past loading), so each element's stress is blended between its NN-remapped value and its SPR-recovered value by the Deborah number, De = (element Maxwell time) / (time since the last remesh): a high-De (cold, elastic) element keeps its NN stress; a low-De (weak, viscous) element takes the SPR average. The blend is a smoothstep in log10(De), controlled by two parameters:

    ParameterDefaultMeaning
    mesh.remesh_deborah_min1.0De at or below which the remeshed stress is purely the SPR recovery.
    mesh.remesh_deborah_max100.0De at or above which the remeshed stress is purely the NN-remapped stress.

    remesh_deborah_min must be positive and less than remesh_deborah_max, or the run exits with a config error (see Exit codes). Widen the gap to blend more of the domain; narrow it to make the switch sharper.

  • The free surface is pinned to its exact physical condition (zero normal and shear stress) after the blend, rather than relying on SPR's one-sided, less reliable extrapolation there, and an element whose shape and neighbors are unchanged by the remesh keeps its pre-remesh stress bit-exactly rather than being re-interpolated at all.

If a node's patch is geometrically degenerate (e.g., a boundary node with fewer neighbours than degrees of freedom), SPR falls back to a simple weighted average of the surrounding element centroid values.

Zienkiewicz, O. C., & Zhu, J. Z. (1992). The superconvergent patch recovery and a posteriori error estimates. Part 1: The recovery technique. International Journal for Numerical Methods in Engineering, 33(7), 1331–1364. https://doi.org/10.1002/nme.1620330702
