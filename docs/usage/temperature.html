Temperature initial and boundary conditions

control.has_thermal_diffusion = yes enables conduction (the default). Fluid heat advection, shear heating and point heat injection also use the temperature update; disabling conduction alone does not disable those features. See Heat transport.

Boundary conditions​

Each face can be insulated (bc.tbc_* = 0) or held at a prescribed temperature (1). The default holds the top at bc.surface_temperature and insulates the base and sides. To hold a hot base and cold top:

[bc]
tbc_z0 = 1
tbc_val_z0 = 1600
tbc_z1 = 1
tbc_val_z1 = 273

Use tbc_x0, tbc_x1 and, in 3D, tbc_y0, tbc_y1 for the sides, with matching tbc_val_* values in K. Intersecting fixed-temperature faces must agree at shared nodes. There is no prescribed heat-flux boundary option.

An explicit thermal boundary is applied at initialization and after remeshing as well as during transport. It can therefore change an initial profile immediately. Without custom thermal boundary settings, the legacy initial profile is retained until the first transport update applies the default top value.

bc.mantle_temperature shapes the initial profiles and supplies the fallback value for a fixed base (tbc_z0 = 1) when tbc_val_z0 is unset. It does not hold an insulated base fixed. Other fixed faces use surface_temperature when their explicit value is unset.

Initial temperature profile​

ic.temperature_option selects how the initial temperature field is built:

temperature_optionProfile
0 (default)Uniform half-space cooling
1Continental thermal gradient
2Equilibrium temperature for crustal radiogenic heating
3Continental thermal gradient with adiabatic mantle
4Uniform background with a Gaussian perturbation
5Linear top-to-base profile with a Gaussian perturbation
90Read from an external grid (e.g., generated by COMSOL)

temperature_option = 0: uniform half-space cooling​

The classic error-function cooling profile between surface_temperature and mantle_temperature, using the thermal diffusivity of material 0 (therm_cond[0] / (rho0[0] * heat_capacity[0])):

[ic]
temperature_option = 0
oceanic_plate_age_in_yr = 60e6   # age of the plate, used in the half-space cooling profile

temperature_option = 1: continental thermal gradient​

A steady-state continental geotherm (crust over mantle) with an exponentially decaying radiogenic heat source in the crust, relaxed toward temperature_option = 0's initial condition over the plate's age:

[ic]
temperature_option = 1
continental_plate_age_in_yr = 100.e6   # age of the plate
radiogenic_heating_of_crust = 1.e-9    # W/kg
radiogenic_crustal_thickness = 30.e3   # m
lithospheric_thickness = 100.e3        # m
radiogenic_folding_depth = 10.e3       # m; e-folding depth of radiogenic heating (shared with option 2)

temperature_option = 2: equilibrium temperature for crustal radiogenic heating​

Like option 1, but for an arbitrary stack of radiogenic-heating layers instead of a single crustal layer, each with its own material (and therefore its own therm_cond, rho0, radiogenic_heat_prod):

[ic]
temperature_option = 2
num_radiogenic_heat_layer = 1       # number of layers
radiogenic_heat_boundry = [-1,-1]   # depth of each layer boundary, top to bottom (m); -1 = model top/bottom
radiogenic_heat_mat_in_layer = [0]  # material index of each layer
radiogenic_folding_depth = 10.e3    # m; e-folding depth of radiogenic heating (shared with option 1)

temperature_option = 3: continental thermal gradient with adiabatic mantle​

A radiogenic continental geotherm, using the same layered [mat] properties as option 2, capped by an adiabatic mantle below (via mantle_temperature and gravity). The radiogenic heating of the top layer is driven by the heat flux parameters below instead of radiogenic_heat_prod, and can be localized under an elliptical "dome" in map view instead of applied uniformly:

[ic]
temperature_option = 3
num_radiogenic_heat_layer = 1       # number of layers (shared with option 2)
radiogenic_heat_boundry = [-1,-1]   # layer boundary depths, top to bottom (m); -1 = model top/bottom
radiogenic_heat_mat_in_layer = [0]  # material index of each layer
radiogenic_heat_dome_center_x = 0.5   # dome center, fraction of mesh.xlength
radiogenic_heat_dome_center_y = 0.5   # dome center, fraction of mesh.ylength (3D)
surface_heat_flux = 70e-3             # W/m^2, background surface heat flux away from the dome
radiogenic_heat_dome_amplitude = 0    # extra surface heat flux at the dome center
radiogenic_heat_dome_width = 0        # dome half-width (m); required (> 0) when this option is used
radiogenic_heat_dome_width_y = 0      # dome half-width in y (3D): 0 = same as x (circular), <0 = infinite (ridge/hinge)
radiogenic_heat_dome_azimuth = 0      # dome rotation (degrees, 3D)

temperature_option = 4 or 5: controlled perturbations​

Option 4 starts at ic.temp_background; option 5 uses the linear profile between bc.surface_temperature and bc.mantle_temperature over mesh.zlength. Both add a Gaussian of amplitude ic.temp_anomaly_amplitude, centred at ic.temp_anomaly_xcenter/ycenter/zcenter, with positive ic.temp_anomaly_xsemi_axis/ysemi_axis/zsemi_axis lengths. The y parameters apply in 3D. Zero amplitude gives the unperturbed profile. The initial profile and active thermal boundaries should describe the same problem; see the convection benchmark.

temperature_option = 90: read from an external grid​

Reads a precomputed temperature field on its own mesh, interpolated onto the DES3D mesh at startup, typically generated by COMSOL:

[ic]
temperature_option = 90
Temp_filename = Thermal.dat         # rows of "x [y] z temperature"
Nodes_filename = Coord.dat          # rows of "x [y] z", may be ordered differently than Temp_filename
Connectivity_filename = Connectivity.dat   # rows of node indices per element (4 per row in 3D)

Material thermal properties​

The thermal diffusivity used above, and the diffusion solved every step, both come from each material's properties in [mat] (one value per material, or a single value broadcast to all materials):

[mat]
heat_capacity = [1e3]        # J/(kg.K)
therm_cond = [3]             # W/(m.K)
radiogenic_heat_prod = [0]   # W/kg; internal heat source for temperature_option = 1-3

mat.max_thermal_diffusivity (default 5e-6 m²/s) supplies the outer timestep's diffusion estimate; it does not clip a material's conductivity or its physical diffusivity. Thermal substeps have an additional bound assembled from the actual transport operator and nodal heat capacity.
