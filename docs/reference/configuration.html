Configuration file

A DynEarthSol model is described by one input file in INI format, passed to the executable:

dynearthsol2d model.cfg

Each parameter belongs to a section, and its full name is section.parameter, for example mat.rheology_type. Inside the file it is written under its section header:

[mat]
rheology_type = elasto-plastic

Parameters left out take their defaults. Lists are written in brackets, [1, 2, 3], with one value per material where a parameter is set per material. A single value applies to every material.

Sections​

SectionControls
[sim]Model name, run length, output and checkpoint intervals, restart
[mesh]Domain size, mesh generation, resolution, quality checks and remeshing
[markers]Lagrangian markers that carry material identity
[control]Gravity, time stepping, mass scaling, damping, the PT solver, and heat and fluid transport
[bc]Velocity, traction, thermal and hydraulic boundary conditions, surface processes
[ic]Initial temperature, stress, weak zones and material layout
[mat]Rheology and material properties, per material
[monitor]Point monitors written as CSV time series
[debug]Diagnostic output

Finding a parameter​

The configuration parameters page lists every parameter with its type, default and description. It is generated from the executables, which remain the authoritative list for their own version. Run one with -h to print the same information for the build you are using:

./dynearthsol2d -h
./dynearthsol2d -h | grep -A2 'rsf'

examples/defaults.cfg in the DynEarthSol repository lists the parameters by section with their default values and short comments. The examples/ and benchmarks/ directories contain complete working inputs.

The User guide and Theory pages describe the parameters that belong to each feature:

FeaturePage
Boundary conditionsVelocity and traction, temperature
Initial stressInitial stress
Weak zonesWeak zones
Mechanical solverChoosing a mechanical solver
RemeshingRemeshing, MMG
Rate-and-state frictionRate-and-state friction
Point monitorsPoint monitors
RestartCheckpointing and restart

An unknown or misspelled parameter stops the run with exit code 11 before any computation; see exit codes.
