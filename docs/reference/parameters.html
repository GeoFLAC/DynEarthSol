Configuration parameters

All parameters accepted by DynEarthSol at source revision 1c7ef34, as printed by dynearthsol2d -h and dynearthsol3d -h. A parameter is written in its section of the input file; see Configuration file. Defaults that differ between 2D and 3D are shown for both.

Types: integer, real, yes/no, text, and list (bracketed values, one per material where the parameter is per material; a single value applies to all).

[mesh]​

Domain size, mesh generation, resolution, quality checks and remeshing.

ParameterTypeDefaultDescription
meshing_optioninteger1How to create the new mesh? 1: rectangular box with roughly uniform resolution 2: rectangular box with rectangular zone of refined resolution 90: read the bounding polygon from a .poly file 91: same as 90, but the max. element size is normalized with resolution. 95: read the mesh from from a .exo file
meshing_elem_shapeinteger0Mesh layout. 0: unstructured triangles (2D) or tetrahedra (3D); 1: regular rectangular cells split into triangles/tetrahedra; 2: equilateral triangles (2D) or a regular tetrahedral layout (3D). All solver elements are simplices.
meshing_verbosityinteger-1Screen output of meshing and remeshing. -1: no stage log (default). 0: the stage log ([metric], [collapse], [freeze], [unfreeze], [require], [corner], [mmg], [restore], [GPU mem] lines: what a remesh re-sized, collapsed, froze, freed and restored) and the mesher's standard report. 1-3: Triangle/TetGen -V levels on top. Warnings print at every level.
meshing_sedimentyes/nonoRefine the elements with sediment marker during remeshing.
tetgen_optlevelinteger3Optimization level for tetgen. 0: no optimization; 1: multiple edge filps; 2: 1 & free vertex deletion; 3: 2 & new vertex insertion. High optimization level could slow down the speed of mesh generation. For 3D only.
xlengthrealrequiredLength of x (in meters)
ylengthrealrequiredLength of y (in meters), for 3D only
zlengthrealrequiredLength of z (in meters)
resolutionrealrequiredSpatial resolution (in meters)
smallest_sizereal0.01The size of smallest element relative to an element with typical resolution. It sets the tiny-element remesh trigger smallest_vol = smallest_size * sizefactor * resolution^NDIMS (sizefactor 0.433 in 2D, 0.118 in 3D: a unit-edge equilateral element's measure) and two lengths, hmin = smallest_size^(1/NDIMS) * resolution and min_dist = (smallest_size * sizefactor)^(1/NDIMS) * resolution. hmin is the Triangle/TetGen node-spacing floor (a remesh deletes interior nodes closer than hmin to a retained node), with MMG in 2D the boundary-segment length below which a remesh merges the segment's two nodes (never a domain corner), and the necking-stop distance of remeshing_option 1, 11 and 13 (see remeshing_option). With options 1, 11 and 13 a remesh removes the nodes off a restored boundary that lie past it or within min_dist of it, and option 2 the interior nodes within min_dist of the new bottom; with options 1 and 10-12 Triangle keeps a boundary node whose two segments are both longer than min_dist, and in 3D TetGen's boundary edge flips move a boundary by at most min_dist; at a receiving wall, option 13 gives the side profile to new material up to min_dist inland of the old wall. With MMG it also sets MMG's size floors (see mmg_remesh_defensive_tiny_ratio).
largest_sizereal30The size of largest element relative to an element with typical resolution, which also caps the coarse zone of a meshing_option = 2 mesh. With MMG it also sets the maximum edge length, hmax = largest_size^(1/NDIMS) * resolution
sediment_sizereal1The size threshold of the refined sediment elements
min_anglereal32Min. angle of all triangles (in degrees), for 2D only
max_steiner_factorreal30Cap on the number of Steiner points Triangle may insert while (re)meshing, expressed as a multiple of the number of input nodes (2D only). This bounds the pathological, non-terminating segment splitting that Triangle can enter when two boundary segments meet at a very small angle (e.g. a highly distorted mesh at extreme strain), which would otherwise spin forever and exhaust memory. The cap is far above any healthy remesh, so normal meshing is unaffected. Set <= 0 to disable the cap (Triangle default: unlimited).
min_tet_anglereal22Min. dihedral angle of all tetrahedra (in degrees), for 3D only
max_ratioreal2Max. radius / length ratio of all tetrahedra, for 3D only
refined_zonexlist[0.4, 0.6]Refining portion of xlength ([d0,d1]; 0<=d0<=d1<=1), for meshing_option=2 only
refined_zoneylist[0.4, 0.6]Refining portion of ylength ([d0,d1]; 0<=d0<=d1<=1), for meshing_option=2 only, for 3D only
refined_zonezlist[0.8, 1]Refined depth interval [d0,d1] as fractions of zlength measured downward from the top (0 <= d0 <= d1 <= 1); meshing_option=2 only.
poly_filenametextmesh.polyInput polygon filename for meshing_option=90 or 91. Triangle .poly format in 2D; TetGen .poly format in 3D. Region attributes select materials when ic.mattype_option=0. Point attributes, point boundary markers and holes are not supported. Also supply mesh.xlength, mesh.ylength and mesh.zlength.
exo_filenametextmesh.exoFilename of the input polygon, for meshing_option=95 only. Meshing software like Trelis is supposed to be used for creating a mesh in the ExodusII format. Limitation: Only box-like domains with six sides are supported. Users still need to provide these parameters: mesh.xlength, mesh.ylength, and mesh.zlength.
quality_check_step_intervalinteger100How often to check mesh quality?
min_qualityreal0.4Min. mesh quality before remeshing (between 0 and 1)
max_boundary_distortionreal0.25Max. distance of boundary distortion before remeshing (in unit of mesh.resolution).
remeshing_optioninteger0How to deal with the boundaries during remeshing? 0: no modification on any boundary. 1: move all bottom nodes to initial depth and delete the side-wall nodes left just above or below it; other boundaries are intact. 2: create a new bottom boundary at the initial depth, other boundaries are intact (2D only, not with MMG remeshing). 10: no modification on any boundary, except small boundary segments might get merged (in 3D with TetGen, see smallest_size). 11: move all bottom nodes to initial depth and delete the side-wall nodes left just above or below it; other boundaries are intact, except small boundary segments might get merged. 12: move all x0 (left) wall nodes to the x of the wall's top corner and delete the nodes left outside, other boundaries are intact. For a wall pushed over a fixed bottom with its push tapered toward it (vbc_x0 = 3 with bottom_shear_zone_thickness), whose foot lags its top. With MMG remeshing, 2D only. 13: move all bottom and side-wall nodes (left/right; also front/back in 3D) to initial dimensions, and give material entering through a side wall the structure recorded at that wall (its side profile). A wall receives while its nodes drift inward between remeshes (by any amount when its vbc at the remesh is inflow, else by more than min(1e-3, max_boundary_distortion) * resolution). It keeps the column (2D) or wall face (3D) recorded when it started receiving (at run start when its vbc is inflow, else at the first remesh at which it receives), and drops it when it neither receives nor has an inflow vbc. Incoming material gets the recorded temperature, layering, radiogenic source, coord0 reference and zero strain at its depth below the wall's top point less the rise surface processes gave it, and in 3D at its along-strike position (a point off the recorded face takes the values of the face's nearest point). A deposit on the wall top gets the profile top's values. Markers a remesh creates in an element at the wall take the layering at the element's centroid and time 0; in an element centred in the deposit, mattype_sediment and the time of a sediment marker of the element, else the remesh time. Temperatures are not re-conducted under a risen surface, so they can differ from the domain beside the wall by up to the near-surface temperature gradient times the rise. Requires MMG when meshing_elem_shape = 0: the restored wall accumulates sub-hmin elements that only MMG collapses. With MMG on an unstructured mesh, a Triangle/TetGen initial mesh first gets its restored-wall elements refined to ~resolution, whatever use_mmg_init says (in 3D under mattype_option 0 this can move a regional-attribute boundary inside the wall band), and every remesh caps the size target at every restored-wall node at resolution (see mmg_aniso_wall_ratio), so the walls can carry more elements than the cfg's sizes give. 14: restore selected reference-boundary components (2D unstructured meshes only; mesh.remeshing_reset_boundaries). On an unstructured mesh (meshing_elem_shape = 0), options 1, 11 and 13 stop the run at a remesh (exit 42) when a top-surface node is within smallest_size^(1/NDIMS) * resolution of the restored bottom, or below it: the domain has necked through.
num_remeshing_reset_boundariesinteger0Number of selected boundary-marker bits for remeshing_option=14.
remeshing_reset_boundarieslist[]Boundary-marker bits to restore, e.g. [1,16]. Single faces restore normal components; two selected faces restore their corner fully.
mmg_remesh_active_plstrainreal0.01Conservative MMG remeshing (always on with MMG): a remesh keeps quiet elements as they are (frozen) and rebuilds the rest. This key is the plastic-strain increment since the last remesh above which an element is refined: MMG may split it (not along an edge it shares with a frozen, MMG-required element) but keeps its existing nodes, so the band's plastic strain is carried verbatim. Distorted or tiny elements are repaired with node motion (see mmg_remesh_defensive_quality_ratio and mmg_remesh_defensive_tiny_ratio), and so is the mesh that restoring a boundary squashed or collapsed or that merging a short boundary segment (see smallest_size) reshaped. Elements far from their size target are freed (see mmg_remesh_size_recovery_ratio), as is the band beside a receiving or outward-drifting restored wall (remeshing_option 13). Boundary nodes stay pinned except the free-surface nodes a surface process moves by more than 1% of resolution per remesh interval (2D only, surface_process_option 1 or 102), the off-bottom nodes of unrestored side walls and slant boundaries, the nodes of repaired elements and the band nodes off an outward-drifting restored wall. Keep it > 0: at 0, incidental yielding makes quiet far-field elements splittable at every remesh. Default 0.01, heuristic: above the increment of incidental yielding, below a localizing band's increment over a remesh interval.
mmg_remesh_defensive_tiny_ratioreal1.5Gap, in element measure, between the tiny-element remesh trigger smallest_vol (see smallest_size) and the smallest elements MMG builds (usemmg=1, meshing_elem_shape = 0; remeshing and MMG-built initial meshes). MMG's minimum edge length is hmin * ratio^(1/NDIMS) (hmin: see smallest_size), so MMG aims to build every element at smallest_vol * ratio or more, which must shrink by this factor before it re-triggers, and a remesh rebuilds any element below smallest_vol * ratio. The ratio also sets MMG's metric floor one step higher, hmin * ratio^(2/NDIMS) (at most MMG's hmax), and the post-remesh quality gate at smallest_vol * sqrt(ratio). Must be >= 1 (at 1 a just-remeshed element re-triggers under any compression); a ratio at or above largest_size / smallest_size is capped just below it, with a warning. Default 1.5 (a 2/3 measure gap), heuristic.
mmg_remesh_defensive_quality_ratioreal1.5MMG remeshing repairs (unfreezes, with its nodes movable except where disjoint material bodies meet) every element of quality below min_quality * this ratio, so a marginal element is rebuilt before it crosses the min_quality remesh trigger instead of triggering another remesh a few steps later. The trigger itself stays at min_quality. Must be >= 1 (1: repair only below the trigger). Default 1.5, heuristic.
mmg_remesh_size_recovery_ratioreal1.4Size recovery in MMG remeshing. A quiet element (e.g. one that entered at ~resolution through a restored inflow wall and advected inland) is freed to coarsen when it is finer by more than this factor than the gradation envelope, the smallest size MMG's gradation (hgrad) allows there given every intentionally fine size target; an element at least 2x its own plastic-strain size target is freed to split. Neither frees an element refined for plastic-strain growth (mmg_remesh_active_plstrain), one on the top surface, one at a material interface (by its own and its neighbours' markers) or one within 4 rings of a restored wall that receives no material, and neither unpins a restored-wall or bottom node; the remesh log's '[unfreeze] size recovery' line counts the top-surface, interface and wall-band skips. On a moving mesh, a Triangle/TetGen initial mesh also gets the 2x split in its weak zone before any field exists, except on a top-surface node or a region boundary ('[weakzone]' log lines). 0 disables all three; otherwise must be > 1 (a margin against re-freeing the legal size transition). Default 1.4 ~ sqrt(2) in edge length (one 2D bisection level), heuristic.
remesh_deborah_minreal1During remeshing the element stress is a Deborah-number-weighted blend of the NN-remapped stress and the SPR recovery, De = Maxwell time / time since the last remesh. The weight is a smoothstep -- the cubic 3t^2 - 2t^3, flat at both ends -- in log10(De): high-De (cold, effectively elastic) elements keep the NN stress, preserving elastic stress memory; low-De (weak, viscous) elements take the SPR average, which suppresses element-scale noise. This sets the De at or below which the remeshed stress is purely the SPR recovery.
remesh_deborah_maxreal100De at or above which the remeshed stress is purely the NN-remapped stress. The default puts the two limits two decades apart, which keeps them clear of the De = 1 crossover while remesh intervals themselves vary by a factor of a few between events; widen it to blend more of the domain, narrow it to make the switch sharper. The window width is otherwise untuned.
is_discarding_internal_segmentsyes/noyesDiscard the initial mesh's internal segments (refined-zone box, .poly internal facets)? 'no' keeps them as Triangle/TetGen constraints across remeshes, but a remesh that deletes one of their nodes (tiny-element repair, node cleanup near a restored boundary) misroutes them, which can make the mesher fail or hang; in 3D with remeshing_option 1 or 10-12 the first remesh that deletes a boundary node drops them all. MMG remeshing (usemmg=1, meshing_elem_shape = 0) requires 'yes': MMG keeps no internal segment.
mmg_debuginteger0Run MMG remesher in debug mode? No:0; Yes:1
mmg_verboseinteger0Verbosity level of MMG remesher. For debugging, set a value greater than 4.
mmg_hausd_factorreal0.01Factor multiplied to param.mesh.resolution to set the Hausdorff distance between original and remeshed surfaces. At 0.01 MMG refines a sharply bent free surface down to its size floor and builds elements below the tiny-element trigger there, so the trigger fires at nearly every quality check: use 0.02-0.05 along a 3D fault scarp and 0.1 on the top/wall ridges next to restored side walls. MMG3D does not bound its top-surface edge swaps between pinned nodes by this distance.
mmg_init_coarsening_factorreal10Coarsening factor for the two-stage TetGen+MMG init mesh. TetGen creates a mesh with element volumes scaled by factor^NDIMS; MMG then refines to target resolution. Higher values = smaller coarse mesh = faster TetGen but more MMG work. Default: 10.
use_mmg_inityes/nonoUse two-stage TetGen+MMG initialization? Requires compilation with USEMMG. Set to yes for metric-aware refinement; no (default) uses plain triangle/tetgen init (MMG still refines its restored walls under remeshing_option 13 and, on a moving mesh, its weak zone: see mmg_remesh_size_recovery_ratio). Under mattype_option 0, which reads the regional attributes as mattypes, a boundary between them stays on the .poly line in 2D and can move by up to about half a coarse element in 3D (see mmg_init_coarsening_factor).
mmg_metric_refine_coeffreal5Plastic-strain sensitivity of the MMG remeshing metric: the target element volume is scaled by 1/(1 + coeff*plastic_strain), so the target edge length by that ratio^(1/NDIMS) (whether a node keeps its finest target: see mmg_metric_refine_recover). 0 disables plastic refinement from a fresh start (the metric floor, the surface-motion inflation of shrinking top elements and the option-13 restored-wall cap still apply). MMG starts from this target except at a node on a required edge (an edge of a frozen element or, in 2D, an option-13 material-interface edge) that belongs to no refined element (see mmg_remesh_active_plstrain): there it starts from the mean length of the required edges through the node, MMG's own rule. Larger values mesh a plastically strained zone finer, down to the metric floor (see mmg_remesh_defensive_tiny_ratio): a shear band can localize narrower, at more elements and, where an elastic, advection or diffusion limit sets dt, a shorter time step. Default 5.
mmg_metric_refine_recoveryes/nonono (default): each node keeps the finest plastic-strain size target (see mmg_metric_refine_coeff) it has had at a remesh, so a refined zone stays refined where the target coarsens, chiefly where plastic strain drops (the remap of rebuilt elements, the 2D top-element plastic-strain decay, a growing top element); the mesh can then hold more elements. Size recovery (mmg_remesh_size_recovery_ratio) measures against the kept size, and material entering through a restored side wall starts unrefined. yes: the target follows the current plastic strain. The record is checkpointed: with no, a restart that lowers mmg_metric_refine_coeff (even to 0) keeps the sizes recorded before it, and a restart that switches from yes to no holds from the last remesh's targets.
mmg_aniso_wall_ratioreal0Anisotropic MMG metric at inflow restored side walls (remeshing_option 13). 0 (default): off, isotropic. >= 1: aspect ratio; the inflow-wall elements are coarsened by this factor normal to the wall and kept fine along it, so the incoming column is carried by thin, wide elements. MMG's hmax (see largest_size) caps the aspect (~5.5 in 2D, ~3.1 in 3D at the default largest_size). Other values below 1 are rejected. Requires USEMMG.
vt_sizereal0.5Cell size of the virtual-topology marker grid (in unit of mesh.resolution), used by the serpentinization grid (mat.phase_change_option 3 with mat.has_serpentinization). 0.5 = half an element edge: the one-element-thick slab crust gets its own wet-crust-dominant cell row instead of averaging with the mantle above, while a cell nominally (elements of edge mesh.resolution) holds ~2.3 markers in 2D (~4.2 in 3D) at the default 4 per element; a refined mesh puts more in each cell. Heuristic, untuned. With serpentinization on it must be > 0, and mesh.resolution * mesh.vt_size must not exceed mat.serpentinization_thickness. The grid is rebuilt at each mesh.quality_check_step_interval and after each remesh.
