# DynEarthSol v2.0 Benchmarks

This directory provides three DynEarthSol benchmark groups. Each has a dedicated `README.md` describing its setup, execution, and requirements.

| Directory | Benchmark | Description |
|---|---|---|
| [`performance/`](performance/README.md) | Compute performance | CPU and GPU throughput across 8 problem sizes (regular and irregular mesh); CPU core-scaling test |
| [`coupling/`](coupling/README.md) | Surface-process coupling | Two-way coupled DynEarthSol–GoSPL 3-D rifting model |
| [`rsf/`](rsf/README.md) | Rate-and-state friction | 108 configurations: simple shear, localization, decollement and strike-slip cases; compatible solver requirements and reproduction limits |
